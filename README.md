# Confam website (demo)

Open `index.html` in a browser. It is one self-contained page: all styles and scripts are inside it.

- Fonts load from Google Fonts (Bricolage Grotesque, Instrument Serif, Geist, Geist Mono), so connect to the internet for the full look. Without it, the page still works with system fonts.
- Pages are hash links: `#home`, `#check`, `#result`, `#maths`, `#how`, `#report`, `#vendors`.
- The live search is not connected. Results use made-up sample data. Try `@glowgadgets_demo`, `0123456789` or `Double your money in 30 days`.
- Forms (report, vendor reply) send nothing.

`earlier-versions/` keeps the previous builds for your case study.
